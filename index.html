Bot Commands

Search a command and copy it with one tap.

.menu Display the main menu
.help Show help information
.ping Check bot response
.alive Check bot status
.owner Owner information
.setting Bot settings menu
.sticker Create a sticker where supported
.yt YouTube search command
.song Music command, if configured
.groupinfo Group information
.admins Show group admins
.tagall Group mention command

Note: Commands work only if they are implemented and enabled in your running bot.
